# Coleções e leitura crítica do acervo

O acervo de 13 fontes Java preserva os créditos de Luigi Scofano de Araujo e Hugo Spadete. Não é compilado pela suíte nova, pois inclui GUI e dependências históricas próprias.

| Tema | Acervo | Código novo |
| --- | --- | --- |
| Fatorial | long sem checagem acima de 20! | Documenta o limite; não altera o passado silenciosamente |
| Multiplicidade | A versão com HashSet elimina repetições | Multiconjunto usa frequências |
| Testes | Dependências originais separadas | PooTest exercita o domínio atual |

**Atividade:** compare adicionar x uma vez e duas vezes. Um conjunto não distingue os casos; um multiconjunto deve distingui-los na igualdade. Localize no código onde essa semântica é representada.
